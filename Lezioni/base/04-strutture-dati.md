# Strutture dati

Si dice **struttura dati** una entità utilizzata per organizzare un insieme di dati legati da un certo tipo di relazione. In python sono presenti le seguenti strutture dati:

* [`Stringhe`](./04-A-stringhe.md): insiemi ordinati di caratteri stampabili.
* [`Tuple`](./04-B-tuple.md): insiemi immutabili di elementi.
* [`Liste`](./04-C-liste.md): insiemi ordinati di elementi.
* [`Set`](./04-D-set.md): insiemi di elementi immutabili e non ordinati.
* [`Dictionary`](./04-E-dictionary.md): insieme di elementi (valori) identificati da una corrispondente parola (chiave).
